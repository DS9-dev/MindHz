### Скачать

- **MindHz-Setup-*.exe** — установщик для Windows 10/11 x64 (права администратора не нужны).
- **MindHz-Portable-*.zip** — портативная версия: распакуйте и запустите `MindHz.exe`; данные хранятся в папке `MindHz-Data` рядом с программой.

Сборка не подписана цифровой подписью: если Windows SmartScreen покажет предупреждение, нажмите «Подробнее» → «Выполнить в любом случае». Проверить целостность файла можно по SHA-256 ниже (`Get-FileHash <файл> -Algorithm SHA256`).

MindHz не является медицинским изделием. Начинайте с тихой громкости.
